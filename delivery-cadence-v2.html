Sample data above is the rows you pasted in chat — replace it with anything else.
BKW view: these rows have no model counts or S3 paths, so this view only looks at arrival times. Each day, an hour counts once (its last delivery). An hour is Recurring when it shows up on at least half the days; otherwise Occasional. "Time seen" is the earliest to latest arrival in that hour, so you can see the usual window. The Include toggle still works here.
How hours get flagged: every row is grouped by dataset and by calendar day. For each day, only the last delivery in a given hour counts (a correction that lands after the scheduled one wins). An hour is Recurring once it shows up on at least half the days in the paste — everything below that is Occasional, i.e. ad-hoc. "Typical models" is the most common count seen at that hour, with the full spread alongside it. Corrections counts how many of those days had a correction land at that same hour (whether or not a scheduled delivery also happened that day). Use the Include toggle above to rerun the whole analysis on only Scheduled rows or only Correction rows — useful for seeing what each one looks like on its own, with the other excluded entirely.
